# Mushroom for Homebrew

```bash
brew install --cask qubit999/tap/mushroom
```

Mushroom is a pixel-art desktop pet for macOS that reminds you to drink water, take breaks and rest your eyes.
7 day free trial, then a free version stays. https://www.getmushroom.app

The cask always installs the current release; Mushroom updates itself after that.
